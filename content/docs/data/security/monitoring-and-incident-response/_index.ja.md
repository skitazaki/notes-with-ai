データセキュリティ監視は、機微または事業上重要なデータへのアクセス、変更、エクスポート、管理操作を観測します。インシデント対応は証拠から何が起きたかを特定し、被害を封じ込め、信頼できる資産を復旧し、統制を改善します。

[データ可観測性](/ja/docs/data/engineering/observability/) はフローが健全で適時に期待どおり動くかを問います。セキュリティ監視は不正な開示、改変、破壊、悪用を示していないかを問います。

## セキュリティ関連テレメトリ

- **データアクセス**: 主体、ワークロード、対象、操作、クエリ、結果量、時刻、生成元、宛先、判断
- **管理変更**: 権限、ロール、ポリシー、共有、公開設定、ログ停止、保持・バックアップ設定
- **データ移動**: エクスポート、ダウンロード、コピー、複製、アカウント間転送、コネクタ、外部共有
- **保護サービス**: 復号、鍵ポリシー、トークン保管庫、マスキング回避、機微データ検出
- **完全性と復旧**: 書き込み、削除、スキーマ、チェックサム、変更不能スナップショット、バックアップ、復元テスト

人とワークロードを一貫して識別し、時刻とリクエストの相関を保ち、ログを改変・削除から守ります。参照や指紋で十分な場合は、機微な生値をログへ残しません。

| シグナル                       | 問い                                     |
| ------------------------------ | ---------------------------------------- |
| 通常と異なる機微データアクセス | 新しい分類、ドメイン、時間帯ではないか   |
| 異常な結果量                   | 通常権限が大量抽出に使われていないか     |
| 狭いクエリの反復               | 小さな結果から保護対象を再構成できないか |
| 大量エクスポート・新規宛先     | 未承認の境界を越えていないか             |
| 権限・共有変更                 | 異常アクセス直前に統制が変わっていないか |
| 予期しない変更・削除           | 完全性や可用性への攻撃ではないか         |
| バックアップ・鍵アクセス       | 復旧や復号能力が狙われていないか         |

## 調査、封じ込め、復旧

ログインだけでなくデータ経路を再構成し、影響データ、操作主体、操作と量、宛先、許可または失敗した統制を特定します。 [メタデータ](/ja/docs/data/metadata/) とリネージは派生資産を示し、 [アクセス制御](/ja/docs/acc/) の証跡は権限取得を説明します。

セッション失効、ワークロード停止、権限縮小、保存先分離、持ち出し遮断、認証情報・鍵のローテーション、共有停止で封じ込めます。証拠や復旧経路を不必要に破壊してはいけません。

既知の正常時点から復元し、完全性と安全な設定を確認し、依存するデータセットやモデルを検証して再発を監視します。機密性の喪失は復元で取り消せないため、後続コピー、受領者、継続アクセスも対応します。

## まとめ

監視はアクセス、管理、移動、保護、復旧のイベントを証拠へ変えます。対応ではコピーと境界を越えてデータを追跡し、経路を封じ込め、信頼できる状態を復元し、完全性を検証して統制を改善します。
