# 日本語の翻訳版の作成

あなたはデジタルテクノロジーの専門家であり、ドキュメント作成のプロフェッショナルです。
一般公開可能な品質で正確性を損なわずに分かりやすく、日本語として自然な文書を作成してください。

翻訳対象のファイルは以下のパスにあります。

`content/docs/ai/_index.md`

日本語版のファイルは `_index.ja.md` として同じフォルダに保存してください。
元の文書構造とメタデータ（日付、タイトル、重み付けなど）を保持してください。

翻訳にあたっては以下の方針に従ってください。

- 文末はですます調で統一してください。
- 各セクションの見出しは日本語を基本としつつ、必要な略語（AI / ML / API / MLOps など）は残して構いません。
- タイトルは自然な日本語を優先し、`Artificial Intelligence` は原則として **人工知能（AI）** と訳してください。
- 本文中で英語の専門用語を残す場合は、初出で日本語のあとにカッコ書きで補足してください。
- 英語の語と日本語を隣接させる場合は、不自然な詰まりを避けるため半角スペースを入れてください。たとえば `AI システム`、`MLOps の運用モデル` のようにしてください。
- 既存のリンク先パス、箇条書き、テーブル構造、カード shortcode は基本的に維持してください。
- 画像の Markdown は維持しつつ、代替テキストは日本語に翻訳してください。
- 画像ファイルについては、日本語版として用意されている画像が同じフォルダにある場合、`.ja.webp` などの日本語向けファイル名へリンク先を調整して構いません。
- ベンダー寄りの言い換えや過度な意訳は避け、概念の境界が曖昧にならないようにしてください。

文量は原文と同程度を目安としてください。
英語の直訳調にはせず、公開ドキュメントとして自然で読みやすい日本語にしてください。

このページは人工知能（AI）セクションのハブページです。単なる一般論の紹介ではなく、以下の点を明確に保ってください。

- 人工知能（AI）が単一技術ではなく、複数の関連分野からなる広い領域であること
- ソフトウェアアーキテクチャ、ソフトウェアエンジニアリング、データ、アクセス制御と接点を持ちながらも、それらのいずれかに還元できない独自の整理軸を持つこと
- 「主要な観点」と「主要なドメイン」が、後続のトピックページへ進むための案内として機能していること
- ハブページとして、読者が順番に読むことを強制されず、自分の関心に応じてトピックページへ移動できること

- Hugo の `cards` shortcode とリンク先パスは維持してください。
- 各カードの `title` と `subtitle` は日本語に翻訳してください。

特に次の点では訳し分けに注意してください。

- `Foundations` はこのページでは「基盤」ではなく **基本概念** としてください。`platform` や `infrastructure` と混同しないでください。
- `perspective` は **観点** とし、「視点」にはしないでください。
- `platforms` は文脈に応じて「プラットフォーム」としてください。`foundations` や `infrastructure` と混同しないでください。
- `hub` は文脈に応じて「ハブ」または「案内役となるページ」と解釈し、順番読了型の「コース」や「学習順路」のように訳さないでください。

訳文では、ハブページとしての導線を明確に保ってください。
特に、主要な観点、主要なドメイン、トピックページ、推奨される出発点の役割が曖昧にならないよう注意してください。
