# 日本語翻訳 — エージェント間の通信と相互運用性

`content/docs/ai/agent-to-agent/_index.md` を `_index.ja.md` に翻訳してください。構造、表、コード例、リンク、メタデータ、ナビゲーションを保持し、画像は `agent-to-agent.ja.webp` を参照してください。

一般公開可能な技術ドキュメントとして、自然で簡潔な日本語にしてください。`Agent-to-Agent Communication and Interoperability` は「エージェント間の通信と相互運用性」、`Agent2Agent Protocol` は「Agent2Agent（A2A）Protocol」、`A2A client` は「A2A クライアント」、`remote agent` は「リモートエージェント」、`Agent Card` は英語表記を維持し、`message` は「メッセージ」、`task` は「タスク」、`part` は「Part」、`artifact` は「成果物」、`delegated authority` は「委任された権限」、`trust boundary` は「信頼境界」とします。

A2A をすべてのマルチエージェント構成と同一視せず、独立して運用されるエージェント間の相互運用境界として説明してください。MCP、通常の API、内部オーケストレーションとの違いと補完関係を維持してください。
