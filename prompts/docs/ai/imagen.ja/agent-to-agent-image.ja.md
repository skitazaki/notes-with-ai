# 画像生成プロンプト — エージェント間の通信

`content/docs/ai/agent-to-agent/agent-to-agent.png` のレイアウト、アイコン、矢印、余白、配色、線、視覚的階層を保持し、画像内のテキストだけを日本語化してください。

次の表記を正確に使用してください。

- **エージェント間の相互運用性**
- **A2A クライアント**
- **作業を開始・委任**
- **A2A サーバー**
- **委任された作業を実行**
- **Agent Card**
- **メッセージ**。直下に小さく **Message** を併記する。
- **タスク**。直下に小さく **Task** を併記する。
- **成果物**。直下に小さく **Artifact** を併記する。

日本語には、英語版および AI ハブ画像の書体感に合う、可読性の高いゴシック体を使用してください。メッセージ、タスク、成果物は日本語を大きな主表記、英語を読みやすい小さな副表記としてください。矢印の方向は変更しないでください。ロゴ、ベンダーブランド、透かし、追加テキスト、人物型ロボット、コード断片を加えないでください。
