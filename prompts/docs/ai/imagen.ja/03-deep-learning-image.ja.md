# 画像生成プロンプト — 深層学習

公開品質の概念図を作成してください。タイトルは「深層学習」です。

目的: 深層学習が層状の表現を学習する手法であり、異なるニューラルアーキテクチャが異なる種類のシグナル・特徴に適していることを伝えること。

中心メッセージ: 深層学習は、積み重ねたニューラル層を通じて、より抽象的な内部表現を学習します。これにより、知覚、言語、音声、生成のための現代的なシステムが可能になります。

構成:

- 中央に、入力から抽象的な表現を経て出力に至る、様式化した多層ニューラルスタックを配置する。
- 中央の3段階には、正確に「入力信号」「学習された表現」「タスク出力」とラベルを付ける。
- 中央の左側に2つ、右側に2つのアーキテクチャ群パネルを配置し、すべてに同じ視覚的重みを与える。
  - 左上: 「CNN」— 空間パターン、視覚
  - 左下: 「RNN / LSTM」— 系列、状態
  - 右上: 「Transformer」— アテンション、スケール
  - 右下: 「拡散モデル／生成モデル」— 反復生成、合成
- 各アーキテクチャ群から、中央にある「学習された表現」へ控えめな接続線を伸ばし、共通する表現学習の考え方に結び付ける。

スタイル: 明るい背景、鮮明なベクタースタイルの技術インフォグラフィック。ごく控えめな奥行き表現、読みやすいラベル、端正な幾何学表現、ニュートラルな中央色とアーキテクチャごとに区別できるアクセント色、16:9横長。

必須事項: 深層学習の層状性を明瞭にし、複数のアーキテクチャ群が同じ広いニューラルパラダイムに属することを示すこと。実装詳細より概念を優先すること。

禁止事項: 微小なノードを多数並べた低レベルのネットワーク図、Transformer だけが重要であるかのような表現、数式、損失曲線、ハードウェアのブランド表現は使用しないこと。
