# 日本語翻訳 — コンテキストエンジニアリング

`content/docs/ai/context-engineering/_index.md` を `_index.ja.md` に翻訳してください。構造、表、メタデータ、ナビゲーションを保持し、画像は `context-engineering.ja.webp` を参照してください。

一般公開可能な技術ドキュメントとして、自然で簡潔な日本語にしてください。`Context Engineering` は「コンテキストエンジニアリング」、`runtime context` は「実行時コンテキスト」、`retrieval` は「検索」、`grounding` は「グラウンディング」、`memory` は「メモリ」、`provenance` は「来歴」、`prompt injection` は「プロンプトインジェクション」とします。

コンテキストエンジニアリングをプロンプト作成だけに狭めず、モデルが実行時に利用する情報を選択、構造化、供給、評価、更新・削除するための設計規律として表現してください。
