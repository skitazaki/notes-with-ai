# Image Generation Prompt - Enterprise AI

Create a publication-quality conceptual illustration titled:

"Enterprise AI"

Help readers understand enterprise AI as the organizational architecture that turns isolated model usage into shared, governed capability.

Core message:

Enterprise AI balances shared platforms and controls with domain-level application ownership.

- Place a central platform block labeled **Shared Enterprise AI Platform**.
- Connect it outward to several domain application zones of equal importance, such as:
  - Product Teams

  - Identity and Access
  - Security and Compliance
  - Integration and Data Connectivity
  - Cost and Capacity Governance
- Add a small top or bottom label showing the balance:
  - Shared Control <-> Domain Autonomy

Style:

- clean editorial infographic
- enterprise architecture aesthetic
- light background
- calm, professional palette with a stable central platform color
- 16:9 aspect ratio

Do:

- make the shared-platform plus federated-usage model easy to understand
- show that many teams connect through the same governed base
- keep enterprise controls visible without overpowering the domains

Do not:

- turn the figure into an org chart

- use vendor logos, cloud badges, or dashboard screenshots
