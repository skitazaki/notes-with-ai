# Image Generation Prompt - Foundation Models

Create a publication-quality conceptual illustration titled:

"Foundation Models"

Purpose:

Help readers see foundation models as reusable capability layers that can be adapted across many modalities and downstream uses.

Core message:

A foundation model is a broad reusable substrate, not a single narrow task model.

Composition:

- Place one large central block labeled **Pretrained Foundation Model**.
- Add a short sublabel inside the center: **Reusable capability base**.
- From the center, fan outward to six compact modality or role panels:
  - Language
  - Vision
  - Speech
  - Code
  - Multimodal
  - Embeddings
- Add a lower adaptation band beneath the center showing:
  - Prompting
  - Fine-Tuning
  - Retrieval
  - Tool Use
- Use arrows to show that downstream systems adapt the shared model rather than training from scratch each time.

Style:

- clean editorial infographic
- vector-style technical illustration
- light background
- calm professional palette with a strong central shape
- readable labels at article width
- 16:9 aspect ratio

Do:

- make the reusable-substrate idea instantly legible
- give all model families similar visual status
- show adaptation as a layer below or around the shared model

Do not:

- turn the image into a vendor landscape
- imply only language models matter
- overload the figure with many downstream application examples
