# Image Generation Prompt - Generative AI

Create a publication-quality conceptual illustration titled:

"Generative AI"

Purpose:

Help readers understand that generative AI is a composed system pattern, not only a model producing text or images.

Core message:

Generative AI becomes useful when model capability is combined with prompts, context, retrieval, tools, structure, and control.

Composition:

- Place a central block labeled **Generative Model**.
- Around it, arrange six equally important system components:
  - Prompts and Instructions
  - Context Engineering
  - Retrieval
  - Tool Calling
  - Structured Outputs
  - Memory and Planning
- Add outputs on the far side as a small cluster:
  - Text
  - Code
  - Images
  - Actions
- Add one thin outer control ring labeled:
  - Evaluation
  - Guardrails
  - Permissions
- Show that the model sits inside a broader system, not at the edge alone.

Style:

- precise editorial infographic
- vector-style technical illustration
- light background
- balanced geometry and moderate contrast
- 16:9 aspect ratio
- readable at docs column width

Do:

- make the system-composition idea obvious
- keep the control ring subtle but visible
- show that several runtime components surround the model

Do not:

- depict generative AI as a single chat bubble
- center the figure on only prompt engineering
- clutter the image with tiny workflow details or product UIs
