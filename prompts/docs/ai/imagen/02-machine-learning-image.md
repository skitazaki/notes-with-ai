# Image Generation Prompt - Machine Learning

Create a publication-quality conceptual illustration titled:

"Machine Learning"

Purpose:

Help readers see machine learning as a disciplined way of learning patterns from data, with distinct learning paradigms and a lifecycle that extends into production.

Core message:

Machine learning turns data into useful behavior through training, evaluation, inference, and feedback.

Composition:

- Use a central left-to-right flow:
  - Data
  - Training
  - Model
  - Inference
  - Monitoring and Feedback
- Above or around the flow, place four compact paradigm panels with equal weight:
  - Supervised
  - Unsupervised
  - Self-Supervised
  - Reinforcement
- Give each paradigm 2 short cues:
  - Supervised: labels, prediction
  - Unsupervised: structure, clustering
  - Self-Supervised: pretraining, representation
  - Reinforcement: actions, reward
- Add a subtle loop from Monitoring and Feedback back toward Data and Training to show continuous improvement.

Style:

- clean editorial infographic
- vector-style technical illustration
- light background
- restrained palette with one highlight color for the lifecycle loop
- clear directional arrows and readable labels
- 16:9 aspect ratio
- suitable for a conceptual docs page

Do:

- make the lifecycle immediately understandable
- keep the four paradigms visually distinct but related
- emphasize that production behavior depends on feedback and monitoring

Do not:

- turn the image into a mathematical chart
- focus on one algorithm family
- overload the image with benchmark metrics or equations
