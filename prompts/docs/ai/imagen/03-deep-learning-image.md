# Image Generation Prompt - Deep Learning

Create a publication-quality conceptual illustration titled:

"Deep Learning"

Purpose:

Help readers understand that deep learning is about layered representation learning, and that different neural architectures are suited to different signal types.

Core message:

Deep learning learns increasingly abstract internal representations through stacked neural layers, enabling modern perception, language, and generation systems.

Composition:

- Place a stylized multilayer neural stack in the center, moving from raw input to abstract representation to output.
- Label the three conceptual stages:
  - Input Signals
  - Learned Representations
  - Task Outputs
- Surround the center with four architecture family panels:
  - CNNs
  - RNNs / LSTMs
  - Transformers
  - Diffusion / Generative Models
- Give each panel 2 short cues:
  - CNNs: spatial patterns, vision
  - RNNs / LSTMs: sequences, state
  - Transformers: attention, scale
  - Diffusion: iterative generation, synthesis
- Show subtle connectors from each architecture family back to the shared central idea of representation learning.

Style:

- crisp technical infographic
- vector-style shapes with subtle depth
- light background
- readable labels and clean geometry
- professional palette with one neutral center and distinct architecture accents
- 16:9 aspect ratio

Do:

- make the layered nature of deep learning visually obvious
- show that several architecture families belong to the same broader neural paradigm
- keep the image concept-first rather than implementation-heavy

Do not:

- draw a dense low-level network with many tiny nodes
- imply transformers are the only relevant architecture
- use formulas, loss curves, or hardware branding
