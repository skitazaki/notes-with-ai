# Image Generation Prompt - AI Applications

Create a publication-quality conceptual illustration titled:

"AI Applications"

Purpose:

Help readers see the application layer as the place where AI capability becomes concrete user value, workflow support, or operational automation.

Core message:

AI applications translate underlying model capability into distinct workflow patterns such as search, assistance, automation, decision support, and domain systems.

Composition:

- Place a central concept labeled **AI Capability Applied to Workflows**.
- Around it, arrange seven application categories with equal visual weight:
  - Search and Retrieval
  - Assistants and Copilots
  - Content Generation
  - Workflow Automation
  - Decision Support
  - Robotics and Embodied Systems
  - Scientific and Industrial Systems
- Add a slim base strip or footer with the key design dimensions:
  - Context
  - Oversight
  - Reliability
  - User Interaction
  - Value Measurement
- Make the categories feel like different application patterns built from the same underlying capability.

Style:

- clean editorial infographic
- concept-first technical illustration
- light background
- balanced radial or grid layout
- clear labels and restrained geometry
- 16:9 aspect ratio

Do:

- make the application categories immediately scannable
- show that user value emerges through workflow fit
- keep the categories broad and durable rather than trendy

Do not:

- turn the image into a product catalog
- make everything look like a chatbot
- overload the figure with domain-specific UI details
