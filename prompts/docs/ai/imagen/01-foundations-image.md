# Image Generation Prompt - Foundations

Create a publication-quality conceptual illustration titled:

"Foundations of Artificial Intelligence"

Purpose:

Help readers grasp at a glance that Artificial Intelligence is not one method. It is a field made of several enduring traditions that answer different questions about intelligent behavior.

Core message:

AI is a broad discipline built from several complementary traditions: symbolic reasoning, search and planning, probabilistic methods, machine learning, and neural approaches.

Composition:

- Place **Artificial Intelligence** at the center as the umbrella field.
- Arrange five equally weighted conceptual branches around it:
  - Symbolic and Rule-Based AI
  - Search and Planning
  - Probabilistic and Statistical Methods
  - Machine Learning
  - Neural and Connectionist Approaches
- Give each branch 2 to 3 tiny supporting labels only:
  - Symbolic: rules, logic, ontologies
  - Search: planning, paths, actions
  - Probabilistic: uncertainty, inference, ranking
  - Machine Learning: data, objectives, generalization
  - Neural: representations, layers, scale
- Add a small side inset or footer strip that clarifies the nesting:
  - AI -> Machine Learning -> Deep Learning
- Show the five branches as related but not sequential.

Style:

- clean editorial infographic
- vector-style technical illustration
- light background
- calm, professional palette with five distinct but coordinated colors
- readable labels at article width
- 16:9 aspect ratio
- suitable for a conceptual docs page hero figure

Do:

- make the field feel broad and structured
- keep all traditions visually balanced
- make the AI/ML/Deep Learning nesting instantly legible
- optimize for quick conceptual orientation

Do not:

- turn the figure into a historical timeline
- imply that newer methods replace older ones completely
- use vendor branding or product logos
- overload the image with paragraphs or formulas
