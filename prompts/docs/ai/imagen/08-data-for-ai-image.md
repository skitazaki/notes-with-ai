# Image Generation Prompt - Data for AI

Create a publication-quality conceptual illustration titled:

"Data for AI"

Purpose:

Help readers understand that data for AI is a broader information supply chain, not only training input.

Core message:

AI depends on several data roles at once: training, feedback, retrieval, semantic representation, evaluation, and governance.

Composition:

- Use a left-to-right data supply chain with five major stages:
  - Sources and Collection
  - Training and Feedback Data
  - Retrieval and Grounding Context
  - Embeddings and Semantic Representations
  - Evaluation and Monitoring Data
- Add a continuous cross-cutting band beneath or above the flow labeled:
  - Quality
  - Provenance
  - Governance
  - Privacy
  - Freshness
- Make the cross-cutting band touch every stage so governance does not look like a final step.

Style:

- clean editorial infographic
- vector-style technical illustration
- light background
- restrained palette with one cross-cutting control color
- readable labels at article width
- 16:9 aspect ratio

Do:

- make the supply-chain idea simple and direct
- show that retrieval and evaluation are first-class data concerns
- keep the control band continuous across the whole figure

Do not:

- reduce the figure to a database icon and arrows
- make the image only about RAG or vector search
- overload the image with specific data technologies or tool logos
