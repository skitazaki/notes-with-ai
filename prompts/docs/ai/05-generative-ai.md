Write a concise reference page titled:
"Generative AI"

You are a senior AI application architect and technical writer explaining systems that generate text, code, images, audio, or structured outputs through interaction with reusable models and context.

Audience:

- AI engineers, product engineers, platform teams, and software architects
- Readers who need a stable explanation of generative AI beyond current product trends

Purpose:

- Define generative AI as an application pattern and capability layer
- Explain the main building blocks used in modern generative systems
- Show how prompting, retrieval, tools, and control flows turn model capability into usable products

Core message:

Generative AI is not just model output generation. It is the broader system design practice of combining model capabilities with context, control, and interaction patterns.

Scope:

- Cover prompting, structured outputs, context engineering, retrieval-augmented generation, fine-tuning, tool calling, memory, planning, and agentic execution
- Explain both content generation and task-oriented systems
- Clarify the differences between chat interfaces, copilots, workflow automation, and agents

Tone and style:

- Neutral, technically grounded, and current without being trend-driven
- Practical for experienced builders
- Focus on durable system patterns

Structure:

1. Definition
   - Define generative AI in terms of model-driven content and action generation.

2. Why it matters
   - Explain why interaction and composition patterns made modern model capabilities broadly useful.

3. Core building blocks
   - Prompts and instruction design
   - Context engineering
   - Retrieval
   - Fine-tuning
   - Tool calling
   - Structured outputs
   - Memory and planning

4. Major system patterns
   - Chat assistants
   - Copilots
   - Retrieval-based assistants
   - Workflow automation
   - Agents and agentic systems

5. Main risks and limits
   - Hallucination
   - Context failure
   - Reliability and control boundaries
   - Security and privacy concerns

6. Relationship to adjacent topics
   - Explain how generative AI depends on foundation models, AI engineering, data for AI, and LLMOps.

Output requirements:

- Write the page in Markdown.
- Include frontmatter with the page title and `weight: 5`.
- Use headings and one concise table mapping building blocks to system roles.

Constraints:

- Do not reduce the topic to prompt engineering alone.
- Do not frame agents as synonymous with all generative AI.
- Do not include vendor comparisons or step-by-step implementation guides.
