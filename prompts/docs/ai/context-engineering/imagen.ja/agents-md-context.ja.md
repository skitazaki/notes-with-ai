# 画像生成プロンプト — コーディングエージェントのコンテキスト

Use case: infographic-diagram

Asset type: documentation hero image

「コーディングエージェントのコンテキスト」というタイトルの、公開ドキュメント品質の概念インフォグラフィックを作成してください。

コーディングエージェントが複数種類の環境情報とタスク入力を使って作業し、`AGENTS.md` は有用なリポジトリコンテキストの一つであることを表現してください。`AGENTS.md` を唯一の入力、最上位の権威、完全なセキュリティ境界として描かないでください。

Data ランディングページのヒーロー画像と同じビジュアル言語を使ってください。

- 技術ドキュメント向けのクリーンな編集デザイン調インフォグラフィック
- 白または非常に明るいウォームグレーの背景
- Inter、IBM Plex Sans、Noto Sans に近い、太く現代的な幾何学系サンセリフの濃紺タイトル
- 同じサンセリフ系書体による、やや小さいスレートグレーのサブタイトル
- 淡い色面を持つ、細い枠線の角丸パネル
- 落ち着いたティール、ブルー、バイオレット、アンバーの配色
- 明瞭なモノラインアイコン、点線コネクター、控えめな矢印、十分な余白
- 強い整列、均等な間隔、エンタープライズドキュメントらしい仕上げ
- 平面的なベクター図解。焦点となる円だけに非常に控えめな影
- 16:9 の横長構図。記事幅でも読める文字サイズ
- ベンダー中立。製品ロゴ、マスコット、ストック写真、透かしを使わない

構図:

上部にタイトルとサブタイトルを配置してください。その下に、三つの大きな角丸パネルを左から右へ並べ、明確な矢印で右側の円形のコーディングエージェント要素へ集約してください。エージェントから、さらに右側の小さな成果領域へ矢印を伸ばしてください。最下部には、全パネルとエージェントへ上向きにつながる、アンバー系の横断的な実行環境レイヤーを配置してください。

パネル 1 はブルー系です。

画像内テキスト（完全一致、かぎ括弧なし）:

- 指示
- システムプロンプト
- ユーザープロンプト
- ポリシーと権限
統治ルール、タスク意図、権限境界を示す簡潔なアイコンを使ってください。

パネル 2 はティール系です。`AGENTS.md` を明確に見せつつ、図全体を支配するほど強調しないでください。

画像内テキスト（完全一致）:

- 「リポジトリコンテキスト」
- 「AGENTS.md」
- 「ソースコード」
- 「README と文書」
- 「設定」

`AGENTS.md` と書かれた文書アイコンを、同じ重みのコード、文書、設定アイコンと並べてください。

パネル 3 はバイオレット系です。

画像内テキスト（完全一致）:

- 「タスクコンテキスト」
- 「会話」
- 「提供ファイル」
- 「現在の変更」
- 「取得した根拠」

会話、添付ファイル、コード差分、選択された根拠を示すアイコンを使ってください。

右側の焦点要素:

画像内テキスト（完全一致）:

- 「コーディングエージェント」
- 「計画・編集・検証」

人型ロボットではなく、抽象的なターミナルとコードの記号を、明瞭な円形フレーム内に描いてください。

成果領域:

画像内テキスト（完全一致）:

- 「検証済みの変更」

チェックマーク付きのコード文書を使ってください。

最下部の横断レイヤーはアンバー系です。

画像内テキスト（完全一致）:

- 「実行環境」
- 「ツールとコマンド」
- 「依存関係」
- 「テスト結果」
- 「作業状態」

実行時の観測がタスクを通じてエージェントの作業コンテキストを更新することを示してください。最終工程として描かず、上向きの点線コネクターを使ってください。

サブタイトル（完全一致）:

「AGENTS.md は、リポジトリ作業を形づくる複数の入力の一つ。」

下部の小さなキャプション（完全一致）:

「信頼できる作業には、適切な指示、リポジトリコンテキスト、タスクの根拠、実行時フィードバックが必要。」

文字要件:

- 指定したテキストを、表記と句読点を変えず、それぞれ一度だけ描く
- タイトルとパネル見出しには太い現代的なサンセリフを使う
- ラベルとキャプションにはレギュラーまたはミディアムのサンセリフを使う
- 十分なコントラストと可読性を保ち、極端に小さい文字を避ける
- 文書アイコン内の `AGENTS.md` は、等幅またはコード風の書体で表現する

避けること:

- `AGENTS.md` をシステムプロンプトとして、またはシステムプロンプトより上位として描く
- 密度が高すぎるアーキテクチャ図や過剰な装飾
- 画像内の長い段落
- 読めないラベル、誤字、重複テキスト、ランダムな文字
- ロボット、人間、脳、魔法表現、SF 風インターフェース
- ベンダーロゴ、クラウド事業者の記号、製品 UI、透かし
