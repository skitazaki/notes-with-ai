# 画像生成プロンプト — ツールと Model Context Protocol

**ツールと Model Context Protocol** というタイトルの、洗練された 16:9 技術インフォグラフィックを作成してください。

**AI クライアント** が **MCP サーバー** へ接続する構図にしてください。サーバーには、**ツール**、**リソース**、**プロンプト** の3つの能力カードを明確に配置します。統制された要求と結果が両者の間を行き来することを示してください。全体を **スキーマ・認可・検証・監査** とラベル付けした制御境界で囲み、右端に **コンテキスト** と **アクション** の2つの結果を置いてください。

明るい背景、青・ティール・インディゴ・アンバーを抑えた配色、ベクター風の幾何学表現、大きく読みやすい日本語サンセリフ体を使います。指定したすべてのラベルを正確に描き、ほかの文字、ロゴ、透かし、製品 UI、人型ロボット、過密な装飾は加えないでください。
