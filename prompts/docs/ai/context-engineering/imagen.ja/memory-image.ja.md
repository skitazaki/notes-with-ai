# 画像生成プロンプト — AI システムにおけるメモリ

**AI システムにおけるメモリ** というタイトルの、洗練された 16:9 技術インフォグラフィックを作成してください。

**取得**、**スコープと保持**、**関連メモリの選択**、**モデル対話**、**修正または削除** を通る明確なライフサイクルを示してください。下部には、**作業コンテキスト**、**セッションメモリ**、**タスクメモリ**、**設定メモリ**、**組織の知識**、**エピソード記録** の6つのメモリカードを配置してください。保持メモリの周囲に、**目的・同意・アクセス・鮮度** とラベル付けした制御境界を設けてください。
