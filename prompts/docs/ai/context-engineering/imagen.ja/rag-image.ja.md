# 画像生成プロンプト — 検索拡張生成（RAG）

**検索拡張生成（RAG）** というタイトルの、洗練された 16:9 技術インフォグラフィックを作成してください。

左から右へ、**統制された情報源**、**索引とメタデータ**、**クエリの解釈**、**検索とランキング**、**根拠の構成**、**根拠に基づく応答** の6段階を明確に示してください。根拠の経路を、**関連性・網羅性・鮮度・来歴・権限** とラベル付けした品質境界で囲んでください。モデルにはコーパス全体ではなく、選択された根拠が渡されることを表現してください。

明るい背景、青・ティール・インディゴ・アンバーを抑えた配色、ベクター風の幾何学表現、大きく読みやすい日本語サンセリフ体を使います。指定したすべてのラベルを正確に描き、ほかの文字、ロゴ、透かし、製品 UI、人型ロボット、過密な装飾は加えないでください。
