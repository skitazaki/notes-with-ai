# Image Generation Prompt — Context for Coding Agents

Use case: infographic-diagram

Asset type: documentation hero image

Create a publication-quality conceptual infographic titled “Context for Coding Agents”.

The image must communicate that a coding agent works from several kinds of environment information and task input, and that `AGENTS.md` is one useful repository-context source among them. Do not present `AGENTS.md` as the only input, the highest authority, or a complete security boundary.

Match the visual language of the Data landing-page hero image:

- clean editorial infographic for technical documentation
- bright white or very light warm-gray background
- dark navy headline in a bold modern geometric sans-serif similar to Inter, IBM Plex Sans, or Noto Sans
- smaller slate-gray subtitle in the same sans-serif family
- thin rounded rectangular panels with very pale tinted fills
- restrained teal, blue, violet, and amber palette
- crisp monoline icons, dotted connector lines, subtle arrows, and generous whitespace
- strong alignment, even spacing, and a polished enterprise-documentation finish
- flat vector-like rendering with very subtle shadows only around focal circles
- 16:9 landscape composition, readable at article width
- vendor-neutral; no product logos, mascots, stock photography, or watermark

Composition:

Place the title and subtitle across the top. Below them, arrange three large rounded panels from left to right, each feeding through clear arrows into a circular coding-agent focal element on the right. From the coding agent, show a final arrow toward a compact outcome area. Add a continuous amber-tinted band across the bottom for live runtime context, visually connected upward to all three panels and the agent.

Panel 1 uses blue accents.

Text (verbatim, without quotation marks):

- INSTRUCTIONS
- System Prompt
- User Prompt
- Policies & Permissions
  Use concise icons suggesting governing rules, task intent, and permission boundaries.

Panel 2 uses teal accents and should make `AGENTS.md` clearly visible without making it dominant over the entire diagram.

Text (verbatim):

- “REPOSITORY CONTEXT”
- “AGENTS.md”
- “Source Code”
- “README & Docs”
- “Configuration”

Use a document icon labeled `AGENTS.md` alongside equally weighted code, book/documentation, and configuration icons.

Panel 3 uses violet accents.

Text (verbatim):

- “TASK CONTEXT”
- “Conversation”
- “Provided Files”
- “Current Changes”
- “Retrieved Evidence”

Use icons suggesting conversation, attachments, a code diff, and selected evidence.

Right-side focal element:

Text (verbatim):

- “CODING AGENT”
- “Plan • Edit • Validate”

Depict an abstract terminal-and-code symbol inside a clean circular frame, not a humanoid robot.

Outcome area:

Text (verbatim):

- “VERIFIED CHANGE”

Use a code document with a checkmark.

Bottom cross-cutting band uses amber accents.

Text (verbatim):

- “RUNTIME ENVIRONMENT”
- “Tools & Commands”
- “Dependencies”
- “Test Results”
- “Working State”

Show that runtime observations can update the agent's working context throughout the task. Use upward dotted connectors rather than depicting the band as a final downstream step.

Subtitle (verbatim):

“AGENTS.md is one of several inputs that shape repository work.”

Small closing caption (verbatim):

“Reliable work depends on the right instructions, repository context, task evidence, and runtime feedback.”

Typography requirements:

- render all supplied text exactly once, with correct capitalization and punctuation
- use a bold modern sans-serif for the title and panel headings
- use a regular or medium sans-serif for labels and captions
- maintain strong contrast and legibility; avoid tiny labels
- keep `AGENTS.md` in a monospaced or code-like type treatment inside its document icon

Avoid:

- presenting `AGENTS.md` as a system prompt or as higher priority than the system prompt
- a dense architecture diagram or excessive decorative detail
- long paragraphs inside the image
- illegible labels, misspellings, duplicated text, or random characters
- robots, human figures, brains, magic effects, or science-fiction interfaces
- vendor logos, cloud-provider symbols, product UI, or watermark
