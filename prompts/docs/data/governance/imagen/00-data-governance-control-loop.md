# Image Generation Prompt — Data Governance Control Loop

Create a polished 1536 × 1024 pixels technical infographic titled **Data Governance Control Loop**.

## Purpose and Core Message

Show the overall governance system as a clockwise feedback loop whose seven stages align with the topic pages. Accountability applies across the loop, metadata connects its elements, and trusted data use can operate through centralized, federated, or hybrid models.

## Composition

Place seven equally weighted stages clockwise around one calm center:

1. **Principles & Operating Model** — compass icon
2. **Ownership & Decision Rights** — accountable person icon
3. **Policies & Standards** — policy document icon
4. **Classification & Obligations** — classification tag or shield icon
5. **Controls & Operations** — gear icon
6. **Evidence & Assurance** — evidence folder or clipboard-check icon
7. **Review & Change** — review arrows icon

Use solid clockwise arrows and clear step numbers. The sequence must read as one loop, not as a maturity model.

In the center place **Trusted Data Use** with three equal small labels **Centralized**, **Federated**, **Hybrid**. Above the loop, place a slim banner **Accountability Across the Loop**. Below the loop, place a slim supporting banner **Metadata: Context & Traceability Across the Loop**. This states metadata's cross-cutting function without repeating labels already present in numbered stages.

## Style and Output

- Clean flat-vector editorial infographic
- Warm off-white background, dark navy typography, teal and blue accents, restrained slate for review
- Consistent icons, rounded cards, uniform line weight, solid connectors only
- Balanced whitespace, no dotted lines, no product branding
- 1536 × 1024 pixels, 3:2 landscape, high-quality raster

## Required Text

Use only these exact labels:

- **Data Governance Control Loop**
- **Accountability Across the Loop**
- **Principles & Operating Model**
- **Ownership & Decision Rights**
- **Policies & Standards**
- **Classification & Obligations**
- **Controls & Operations**
- **Evidence & Assurance**
- **Review & Change**
- **Trusted Data Use**
- **Centralized**
- **Federated**
- **Hybrid**
- **Metadata: Context & Traceability Across the Loop**

## Do Not

- Add other labels or explanations.
- Make Federated the target state or a numbered stage.
- Emphasize Metadata over the complete loop.
- Repeat Policies, Controls, Evidence, or any numbered-stage label in the metadata banner.
- Use dotted lines, crossed connectors, decorative particles, glossy 3D, photography, logos, or watermarks.
