# Image Generation Prompt — Compliance, Controls, and Auditability

Create a polished 1536 × 1024 pixels technical infographic titled **Compliance, Controls & Auditability**.

## Purpose

Show how the three subjects named in the page title connect without repeating the policy hierarchy. Compliance maps applicable requirements to control objectives. Controls operate and produce evidence. Auditability uses reliable evidence to reconstruct what happened and support assurance. Findings return through remediation and verification to improve the control.

## Core Message

Compliance establishes what must be satisfied and how it maps to governance. Controls provide the operating mechanism. Auditability makes operation reconstructable and supports assurance and improvement.

## Composition

Use three large, equal-width main columns on one horizontal axis:

1. **Compliance** — clipboard-check icon; contains two small subordinate items, **Applicable Requirements** and **Mapping**
2. **Controls** — gear icon; contains **Control Objective** above **Operation**
3. **Auditability** — evidence-folder icon; contains **Evidence** leading to **Assurance**

Connect Compliance to Controls and Controls to Auditability with two prominent solid right-pointing arrows. The three title subjects must dominate and receive equal visual weight.

Below the three columns, show one quiet closed improvement path: **Finding → Remediation → Verification**, followed by one solid return arrow to Controls. Start the path with one short downward connector from Auditability to Finding. Keep this feedback path visually subordinate to the main three-column relationship.

Use restrained whitespace and simple containment. The reader should first see Compliance → Controls → Auditability, then inspect the contents of each column, then notice the improvement path.

## Relationship to the Governance Hub

The figure is a focused expansion of the hub stages **Controls & Operations**, **Evidence & Assurance**, and **Review & Change**. Do not redraw the complete governance control loop and do not repeat the Policy → Standard → Control figure.

## Style

- Clean editorial infographic for technical documentation
- Crisp flat-vector shapes, simple geometry, and balanced whitespace
- Warm off-white background with dark navy typography and outlines
- Teal for Compliance, blue and slate for Controls, restrained violet for Auditability and Assurance
- Consistent flat icon family, rounded containers, and uniform line weight
- Solid connectors only
- High-contrast text readable at documentation-column width
- Vendor-neutral, timeless, no branding

- Add Policy or Standard nodes.

- Make Evidence or Assurance a fourth main column.
- Connect Verification to Assurance.
- Use competing reading directions, crossing lines, dotted connectors, circular decorative arrows, extra text, tiny labels, ornamental backgrounds, glossy 3D, photography, logos, or watermarks.
