# 画像生成プロンプト - コンプライアンス、管理策、監査可能性

**コンプライアンス、管理策、監査可能性** というタイトルの、1536 × 1024 ピクセルの高品質な技術インフォグラフィックを作成してください。

## 目的

ポリシー階層を繰り返さず、ページタイトルに並ぶ三つの主題の接続を示します。コンプライアンスは適用要件を統制目標へ対応付け、管理策は運用されて証跡を生成し、監査可能性は信頼できる証跡から事実を再構成して保証を支えます。発見事項は是正と完了確認を経て管理策の改善へ戻ります。

## 要素配置

同じ水平軸上に、同じ幅と同じ見出し強度の三つの大きな主列を配置してください。

1. **コンプライアンス** — クリップボードとチェックのアイコン。内部に小さく **適用要件** と **対応付け**
2. **管理策** — ギアのアイコン。内部に **統制目標** と **運用**
3. **監査可能性** — 証跡フォルダーのアイコン。内部で **証跡** から **保証** へつなぐ

コンプライアンスから管理策、管理策から監査可能性へ、2本の目立つ右向き実線矢印で接続してください。三つの主題を同格の主構造として見せます。

三列の下に、控えめな改善経路 **発見事項 → 是正 → 完了確認** を配置し、完了確認から管理策へ1本の実線矢印で戻してください。監査可能性から発見事項へ短い下向き接続線を1本だけ使用します。改善経路は主構造より小さくしてください。

最初に「コンプライアンス → 管理策 → 監査可能性」を読み、次に各列の内部、最後に改善経路へ視線が移るよう、余白と包含関係を調整してください。

## ハブ図との関係

この図は、ハブ図の **管理策と運用**、**証跡と保証**、**レビューと変更** を詳しく説明するものです。完全な制御ループや、ポリシーから管理策への図を再掲しないでください。

## 実施事項

- コンプライアンス、管理策、監査可能性を同じ幅と見出し強度で示してください。
- 証跡と保証を監査可能性の内部に配置してください。
- 改善経路を管理策へ戻してください。
- 指定文字を正確に描画してください。

## 禁止事項

- ポリシーまたは標準のノードを追加しないでください。
- 義務からポリシー、統制目標、管理策、証跡へ進む経路を主構造にしないでください。
- 証跡や保証を第四の主列にしないでください。
- 完了確認を保証へ接続しないでください。
- 競合する読み方向、交差線、点線、装飾的な円形矢印、指定外の文字、小さすぎるラベル、装飾背景、光沢3D、写真、ロゴ、透かしを使用しないでください。
