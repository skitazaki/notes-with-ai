# 画像生成プロンプト - データガバナンスの制御ループ

**データガバナンスの制御ループ** というタイトルの、1536 × 1024 ピクセルの高品質な技術インフォグラフィックを作成してください。

## 目的と中心メッセージ

ハブのトピックページに対応する7段階を、時計回りのフィードバックループとして示します。説明責任はループ全体に適用され、メタデータが要素を接続します。信頼できるデータ活用は中央集権、連合型、ハイブリッドのいずれでも実現できます。

## 要素配置

中央の周囲に、同じ強調度の7段階を時計回りに配置してください。

1. **原則と運用モデル** — コンパス
2. **オーナーシップと意思決定権** — 説明責任を持つ人物
3. **ポリシーと標準** — ポリシー文書
4. **分類と義務** — 分類タグまたは盾
5. **管理策と運用** — ギア
6. **証跡と保証** — 証跡フォルダーまたはチェック付きクリップボード
7. **レビューと変更** — レビュー矢印

実線の時計回り矢印と明瞭な段階番号を使用してください。成熟度モデルではなく、一つの循環として読めるようにします。

中央に **信頼できるデータ活用** を置き、その下に同格の小さなラベル **中央集権**、**連合型**、**ハイブリッド** を配置します。ループ上部に細いバナー **ループ全体の説明責任**、下部に細い支援バナー **メタデータ：ループ全体の文脈とトレーサビリティ** を配置します。番号付き段階にすでにある用語を繰り返さず、メタデータの横断的な機能を示します。

## 視覚スタイルと出力

- クリーンな編集系フラットベクター図
- 温かみのあるオフホワイト背景、濃紺の文字、ティールとブルーのアクセント、レビューには控えめなスレート
- 統一アイコン、角丸カード、均一な線幅、実線接続だけ
- バランスの取れた余白、製品ブランドなし
- 1536 × 1024 ピクセル、3:2 横長、高品質ラスター

## 禁止事項

- 指定外のラベルや説明文を追加しないでください。
- 連合型を目標状態または番号付き段階にしないでください。
- メタデータをループ全体より強調しないでください。
- メタデータバナーでポリシー、管理策、証跡、または番号付き段階の用語を繰り返さないでください。
- 点線、交差線、装飾粒子、光沢3D、写真、ロゴ、透かしを使用しないでください。
