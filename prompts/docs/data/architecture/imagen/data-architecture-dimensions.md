# Image Generation Prompt - Data Architecture Dimensions

Create a polished 1672 × 941 pixels (16:9) technical infographic titled exactly **Data Architecture**.

Communicate one clear idea: data architecture requires decisions across six dimensions, while metadata, governance, security, privacy, quality, and observability apply across all of them. Keep the image conceptual, calm, spacious, and immediately understandable.

## Composition

Place **Data Architecture** at the center, with the subtitle **Six dimensions of architectural decisions**. Arrange exactly six equally weighted areas around it in a balanced radial or hexagonal composition with generous whitespace.

Each area must contain only the specified heading, question, and one minimal abstract icon:

- **Origin** — **Where does data originate?** — source or input icon
- **Movement** — **How does data move?** — directional-flow icon
- **Storage & Processing** — **Where does data live and change?** — storage and transformation icon
- **Serving** — **How is data consumed?** — interface or output icon
- **Ownership** — **Who owns it?** — team or domain icon
- **Trade-offs** — **What are we optimizing for?** — balance or decision icon

The six areas must read as parts of one coherent decision framework, not as independent feature cards.

## Cross-Cutting Concerns

Place one visually quiet foundation or horizontal layer beneath the six decision areas. Label it **Cross-Cutting Concerns** and include exactly these terms:

**Metadata · Governance · Security · Privacy · Quality · Observability**

Use a subtle shared plane, band, or underlay to show that this layer applies across all six dimensions. Do not place the concerns around the perimeter or give them separate icons, definitions, callouts, boxes, or connectors.

## Visual Direction

Match the established Notes with AI illustration style: solid opaque white or very light neutral background, large dark-navy title, crisp sans-serif typography, flat vector graphics, thin consistent outlines, restrained geometric shapes, subtle pale fills, generous whitespace, strong alignment, and minimal shadows. Use a limited professional palette with no more than one restrained accent color per decision area.

Maintain three clear levels of visual hierarchy:

1. **Data Architecture**
2. The six decision dimensions and their questions
3. **Cross-Cutting Concerns** and its six terms

Keep all text legible at documentation-column width. Render every specified title, heading, question, and concern exactly once and exactly as written.

Do not add technologies, products, vendors, architecture patterns, implementation examples, pipelines, extra explanatory text, outer rings, perimeter callouts, complex arrow networks, multiple icons per decision area, photographic elements, 3D effects, gradients, decorative clip art, or watermarks. Do not make the illustration resemble a cloud architecture diagram.
