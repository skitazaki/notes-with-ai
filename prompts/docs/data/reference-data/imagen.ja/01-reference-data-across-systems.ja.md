# 画像生成プロンプト - システムをまたぐ参照データ

英語版の `reference-data-across-systems.png` を入力画像として使用し、構図、階層、配色、矢印、余白、3つのシステムカードを維持したまま、日本語版を作成してください。

出力：

- 16:9
- 1600 × 900 ピクセル程度
- WebP へ変換可能な高品質ラスター画像

テキストの置き換え：

- `Reference Data across systems` -> `システムをまたぐ参照データ`
- `Enterprise Reference Data` -> `企業共通の参照データ`
- `Country` -> `国`
- `Currency` -> `通貨`
- 強調行の `Status` -> `状態`
- `mappings / distribution` -> `マッピング／配信`
- `Different attributes and codes, shared meaning: ACTIVE` -> `異なる属性名とコード、共通する意味：ACTIVE`

次のシステム名、属性名、コード値は変更しないでください。

- `CRM`
- `ERP`
- `Analytics`
- `Status = Active`
- `State Code = A`
- `is_status = 1`
- `JP`
- `JPY`
- `ACTIVE`

日本語を正確かつ読みやすく描画してください。レイアウト変更、新しい要素、ロゴ、透かし、グラデーション、3D 表現は追加しないでください。
