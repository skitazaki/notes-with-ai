## authoritative の訳し方

MDM における _authoritative_ は「権威」ではなく、以下の意味として扱ってください。

- **そのデータを正として信頼できる**
- **組織として公式に採用する**
- **基準となる**

**authoritative source** は「最も信頼できる情報源」という意味であり、「権威者が作った」という意味ではありません。

このページでは、原則として **「正となる」** または **「信頼できる」** を優先し、**「権威ある」** とは訳さないでください。

推奨する訳し方は以下のとおりです。

- authoritative source -> 正となる情報源 / 信頼できる情報源
- authoritative data -> 正となるデータ
- authoritative record -> 正となるレコード
- authoritative version -> 正式な版 / 正となる版
- authoritative system -> 正本を管理するシステム / 基準となるシステム

冒頭定義など、文全体として自然さを優先する場合は、次のような表現を使って構いません。

> マスタデータ管理（Master Data Management、MDM）とは、組織の中核となる業務エンティティについて、システム間で正となる一貫したデータ表現を維持するためのデータ管理の実践です。

**Single Source of Truth** と混同しやすいため、**「唯一の正しい」** という訳は避けてください。
