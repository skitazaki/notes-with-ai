# 画像生成プロンプト — 横断的関心事としてのデータプライバシー

**データプライバシー** ドキュメントハブページ向けに、公開品質の概念図を作成してください。

目的:

データプライバシーが、データエコシステムにおける横断的な専門領域であることを示します。プライバシーには「人に関する情報を責任を持って取り扱う」という固有の主眼があり、複数の隣接領域に依存すると同時に、それらのあり方にも影響を与えます。この図では、プライバシーが情報セキュリティ、データガバナンス、コンプライアンス、データ品質、AIガバナンスと同義ではないことを明確にしてください。

想定読者:

- テクノロジーリーダーとアーキテクト
- データプラットフォームエンジニアとガバナンス実務者
- データシステムを理解しているが、必ずしもプライバシーの専門家ではないシニアエンジニア

中心メッセージ:

プライバシーは、データライフサイクル全体において、人に関する情報を処理してよいか、またどのように処理すべきかを規定します。セキュリティ、データガバナンス、コンプライアンス、データ品質、AIガバナンスは、それぞれ異なる能力を提供しながら、互いに関連しています。

構成:

- 中央に **データプライバシー** と明記した、明確に主役となる円または角丸パネルを配置してください。
- 中央のサブタイトルは **人に関する情報の責任ある取扱い** としてください。
- その周囲に、接続された6つのパネルを均衡の取れた放射状レイアウトで配置してください。複数の円を重ねた文字どおりのベン図は使用しないでください。読みにくくなり、各領域が同一であるという誤った印象を与えます。
- 中央と周囲のパネルの間に、控えめに重なり合うハロー、共有境界の弧、または接続バンドを用いて相互依存性を表現してください。
- 周囲のパネルには、次のラベルと短い説明を必ず含めてください。
  - **情報セキュリティ** — 不正なアクセス、改ざん、紛失から保護する
  - **データガバナンス** — オーナーシップ、方針、意思決定権を確立する
  - **コンプライアンス** — 適用される義務を検証可能な要件へ変換する
  - **データ品質** — 正確で利用目的に適した情報を支える
  - **AIガバナンス** — 責任あるAIデータ利用と自動化された意思決定を監督する
  - **データライフサイクル** — 収集、利用、共有、保持、削除をつなぐ
- 各周囲パネルから中央のデータプライバシーへ向かう方向性のあるコネクターを使用してください。コネクターは貢献と相互作用を示すものであり、線形の処理順序や階層を示すものではありません。
- 外周には細いライフサイクルのリング、または目立ちすぎない周辺ラベルとして **収集 → 保存 → 利用 → 共有 → 保持 → 削除** を含めてください。これにより、プライバシーが継続的に適用されることを表現します。

視覚的な優先順位:

- データプライバシーを最も大きなラベル要素とし、視線の中心にしてください。
- 周囲の6領域は、同等の視覚的な重みで配置してください。
- すべてのテキストを短く大きくし、ドキュメント本文の横幅でも読めるようにしてください。
- アイコンは補助的な手がかりとしてのみ使用してください。セキュリティには盾、ガバナンスにはコンパス、コンプライアンスにはチェックリスト、品質にはチェックマークまたはデータグリッド、AIガバナンスには接続ノード、ライフサイクルには循環矢印を使用します。

スタイル:

- 技術ドキュメント向けの、クリーンなエディトリアル・インフォグラフィック（洗練された出版物の編集デザイン）
- 鮮明なベクタースタイルの幾何学図形と、抑制の効いた線表現
- 明るい背景と、アクセシブルで十分なコントラストを持つテキスト
- プライバシーには濃い青またはティールを使い、接続する各領域には抑えた異なるアクセントカラーを使うプロフェッショナルな配色
- フラット、またはごく控えめな奥行き表現。光沢のある3D効果は使わない
- ベンダー中立で、時代に左右されず、概念を主役にする
- 16:9の横長比率

必須事項:

- プライバシーがすべての領域を所有するかのように見せず、各領域の固有の役割を明確にする
- セキュリティがデータを保護し、プライバシーが適切な処理と利用を規定することを強調する
- プライバシーがライフサイクル全体で機能することを示す
- 図を落ち着いて素早く読めるよう、十分な余白を残す

禁止事項:

- ベンダーロゴ、規制機関のロゴ、国旗、または特定の法域を示す記号を使わない
- 法的助言、コンプライアンス認証、監視を想起させる表現、プライバシーを鍵だけで表現する比喩、ストック写真風のビジネスパーソンを描かない
- 高密度なシステムアーキテクチャ、フローチャート、ダッシュボード、データパイプラインにしない
- 6方向のベン図、読めないほど小さい説明文、または本文横幅で判読できないテキストを使用しない
- プライバシーが単なるセキュリティ機能、あるいは最後に行うコンプライアンス確認であるかのように示さない
