# 画像生成プロンプト — データ品質の観点

**データ品質の観点** というタイトルの、1536 × 1024 ピクセルの高品質な技術インフォグラフィックを作成してください。

## 目的と中心メッセージ

6つの安定した中核となる品質観点と、特定の文脈に応じてモデルを拡張する5つの選択的なグループを示します。拡張グループは中核に依存しますが、互いに同格です。処理順序や成熟度レベルとして表現しないでください。

## 要素配置

3:2の横長キャンバスに、厳密な直線基調の3列グリッドを使用してください。

- 中央列に **中核となる品質観点** という明確な縦長の長方形を配置します。その内部に同じ大きさの長方形セルを2列×3行で配置し、**正確性**、**完全性**、**一貫性**、**適時性**、**一意性**、**妥当性** を入れます。
- 左列に **構造に関する拡張** と **実行時の拡張** を、それぞれ独立した長方形パネルとして配置します。
- 右列に **意味に関する拡張** と **AIに関する拡張** を、それぞれ独立した長方形パネルとして配置します。
- 中央列の下に **ガバナンスに関する拡張** を横長の長方形パネルとして配置し、同じグリッドに整列させます。
- 各拡張パネルと中核を、短い直線の細い実線1本だけで接続します。拡張パネル同士は接続しません。
- すべてのパネルを十分な余白で分離します。角は直角、または最大4 pxのごく小さい角丸にしてください。

安定した中核と選択的な周辺要素として読める構成にします。花、車輪、軌道、循環、標的、ベン図のように見せないでください。

## パネルの詳細

各拡張パネルに、単純な線画アイコン1つと指定した例を配置してください。

- **構造に関する拡張** — スキーマまたは関係のアイコン。**参照整合性**、**エンティティ整合性**、**準拠性**
- **実行時の拡張** — 監視アイコン。**更新鮮度**、**データ量の異常**、**分布ドリフト**、**パイプライン信頼性**
- **意味に関する拡張** — 意味または人のアイコン。**関連性**、**解釈可能性**、**理解可能性**、**アクセス可能性**
- **ガバナンスに関する拡張** — 盾またはリネージのアイコン。**追跡可能性**、**監査可能性**、**ポリシー準拠**、**保持要件への準拠**
- **AIに関する拡張** — モデルまたはネットワークのアイコン。**代表性**、**バイアスと公平性**、**特徴量の安定性**、**再現性**

## 視覚スタイルと出力

- クリーンな編集系フラットベクター図。専門的なエンタープライズアーキテクチャの外観
- 温かみのあるオフホワイト背景、濃紺の文字、控えめなティール、ブルー、グリーン、アンバー、バイオレットのアクセント
- 明瞭な長方形の罫線、均一な線幅、単純な線画アイコン、厳密な整列、十分な余白
- 記事幅でも読みやすい文字。日本語の誤字を避け、フル解像度で24 px未満の文字を使用しない
- 1536 × 1024 ピクセル、正確な3:2横長、高品質ラスター

## 禁止事項

- 円、リング、円弧、花弁、ローブ、カプセル、ピル形状、角が大きく丸いカード、曲線の外枠を使用しないでください。
- 順序、拡張グループ間の階層、時計回りの流れを示さないでください。
- 定義、副題、脚注、凡例、番号、装飾的な説明文、指定外のラベルを追加しないでください。
- 必須ラベルの重複、省略、略記、言い換えをしないでください。
- グラデーション、影、光沢3D、写真、装飾粒子、ロゴ、透かしを使用しないでください。
