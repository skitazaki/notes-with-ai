# 画像生成プロンプト — 品質観点から運用管理まで

**品質観点から運用管理まで** というタイトルの、1536 × 1024 ピクセルの高品質な技術インフォグラフィックを作成してください。

## 目的と中心メッセージ

データ品質の実務で混同されやすい概念を区別します。品質観点がどのように測定、評価、管理され、観測された不具合が運用対応にどのようにつながるかを示してください。

## 要素配置

同じ大きさの明確に分離した長方形グループパネルを、横1行に3つ配置してください。3つのパネルは高さと幅を統一し、上端と下端を同じ水平線に揃えます。

左から右へ、次の順序で配置してください。

1. **定義と測定**
2. **評価**
3. **運用**

隣接するグループパネル間の余白に、短い右向きの水平矢印を1本ずつ置きます。各矢印は余白の垂直方向中央に配置してください。矢印は3つのグループ間の関係だけを示し、個別のカードに触れたり接続したりしないでください。

**定義と測定** パネルの内部には、同じ大きさのカードを次の順序で上から下へ縦に積みます。

1. **品質観点**
2. **メトリクス**

**評価** パネルの内部には、同じ大きさのカードを次の順序で上から下へ縦に積みます。

1. **ルール**
2. **制約**
3. **チェック**

**運用** パネルの内部には、同じ大きさのカードを次の順序で上から下へ縦に積みます。

1. **シグナル**
2. **インシデント**
3. **SLA**

内部の間隔を均等にし、すべてのカードを各グループパネルの中央に揃えてください。カード間には線や矢印を一切描かないでください。概念間の関係は、カード同士の配線ではなくグループへの所属によって表現します。

パネル内部には、3つのグループで共有する水平なカード行を3段設けます。1段目は **品質観点**、**ルール**、**シグナル**、2段目は **メトリクス**、**制約**、**インシデント**、3段目は **チェック**、**SLA** の上下位置をそれぞれ揃えてください。**定義と測定** の3段目は意図的な空欄にします。8枚のカードはすべて、幅と高さを完全に統一してください。

各カード内に短い説明を1つ入れます。角は直角、または最大4 pxのごく小さい角丸にしてください。

## カード内の正確な文言

- **品質観点** — 何の品質を評価するか
- **メトリクス** — どのように測定するか
- **チェック** — どのように検証するか
- **制約** — データモデルが何を強制するか
- **ルール** — どの条件を許容するか
- **シグナル** — どの挙動を観測したか
- **インシデント** — どの不具合に対応が必要か
- **SLA** — どのサービス目標を適用するか

## 視覚スタイルと出力

- クリーンな編集系フラットベクター図。専門的なエンタープライズアーキテクチャの外観
- 温かみのあるオフホワイト背景、濃紺の文字、ティールとブルーのアクセント。インシデントには控えめなアンバー
- 明瞭な長方形の罫線、均一な線幅、単純な線画アイコン、厳密な整列、十分な余白
- 記事幅でも読みやすい文字。日本語の誤字を避け、フル解像度で26 px未満の文字を使用しない
- 1536 × 1024 ピクセル、正確な3:2横長、高品質ラスター

## 画像内で使用する文字

上記のタイトル、3つのグループ見出し、概念ラベル、説明文だけを使用してください。すべての文言を一字一句そのまま、各1回だけ表示してください。

## 禁止事項

- 円、リング、円弧、カプセル、ピル形状、角が大きく丸いカード、曲線の接続線を使用しないでください。
- カードを結合したり、8つの概念すべてを単一の直線的なライフサイクルとして表現したりしないでください。
- カードを列の間に置いたり、重ねたり、段違いに配置したり、斜めに配置したりしないでください。
- 垂直、斜め、分岐、直角に曲がる接続線、またはカード同士を結ぶ接続線を描かないでください。
- **ルール** または **制約** を **メトリクス** や **チェック** に直接接続しないでください。
- **SLA** を **シグナル** や **インシデント** に直接接続しないでください。
- 例、凡例、番号、装飾的な説明文、指定外のラベルを追加しないでください。
- 必須文言の重複、省略、略記、言い換えをしないでください。
- グラデーション、影、光沢3D、写真、装飾粒子、ロゴ、透かしを使用しないでください。
