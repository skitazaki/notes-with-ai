# 画像生成プロンプト - セキュリティ運用サイクル

英語版の `security-operating-cycle.png` を入力画像として使用し、円環構図、6 段階の位置、矢印、配色、視覚的階層、余白を維持したまま、日本語版を作成してください。

画像内のタイトルは正確に次のとおりとします。

`セキュリティ運用サイクル`

出力：

- 16:9
- 1600 × 900 ピクセル程度
- WebP へ変換可能な高品質ラスター画像

目的：

データセキュリティハブの「セキュリティ運用サイクル：保護を維持する方法」にある Mermaid 図を置き換えます。これはデータ状態の順序ではなく、データライフサイクルのすべての状態に適用する継続的な管理ループであることを明確に示してください。

テキストの置き換え：

- `Security Operating Cycle` -> `セキュリティ運用サイクル`
- `Sustained data protection` -> `継続的なデータ保護`
- `Understand` -> `理解`
- `inventory, location, lineage` -> `棚卸し、場所、リネージ`
- `Classify & Assess` -> `分類と評価`
- `sensitivity, exposure, threats` -> `機密性、露出、脅威`
- `Protect` -> `保護`
- `encryption, masking, secure handling` -> `暗号化、マスキング、安全な取り扱い`
- `Control` -> `制御`
- `least privilege, isolation, egress` -> `最小権限、分離、持ち出し制御`
- `Detect` -> `検知`
- `audit, anomalies, extraction` -> `監査、異常、抽出`
- `Respond & Recover` -> `対応と復旧`
- `contain, investigate, restore, verify` -> `封じ込め、調査、復元、検証`
- `lessons` -> `学習`
- `Continuous activities applied across every data lifecycle state.` -> `データライフサイクルのすべての状態に適用する継続的な活動`

制約：

- 指定した日本語を正確かつ読みやすく描画してください。
- 6 段階を時計回りの途切れない 1 つの円環として示してください。
- `対応と復旧` から `理解` へ戻る矢印と `学習` のラベルを明確にしてください。
- セキュリティ運用サイクルとデータライフサイクルの違いを維持してください。
- データがストレージシステム間を移動する図として描かないでください。
- 英語版からレイアウト、要素数、視覚的階層、配色を変更しないでください。
- 新しい説明文、製品名、ベンダーロゴ、コンプライアンスバッジを追加しないでください。
- 南京錠、巨大な盾、ハッカー、フードを被った人物、二進数背景、サーバーラック写真、地球、クラウド事業者ロゴなど、一般的なサイバーセキュリティのストック表現を使わないでください。
- 3D 表現、グラデーション、過剰な影、透かしを追加しないでください。
