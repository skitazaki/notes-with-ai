# Image Generation Prompt - Data-Centric Defense in Depth

Create a publication-quality technical infographic titled exactly:

"Data-Centric Defense in Depth"

Output dimensions and format:

- 16:9 aspect ratio
- suitable for display at 1600 × 900 pixels
- clean raster output that can be converted to WebP

Purpose:

Replace the first Mermaid diagram on the Data Security hub. Communicate that data requires layered protection wherever it resides or moves, and that monitoring and detection span every defensive layer. The central message is: protect the data across systems and boundaries, not merely the perimeter around one system.

Composition:

- Use a centered, bottom-to-top layered composition with five clearly separated horizontal layers.
- Place the most important protected asset in a compact top-center panel labeled exactly:
  - `Data`
  - `at rest, in transit, and in use`
- Directly beneath the Data panel, stack these four defensive layers in this exact order from nearest to the data to outermost:
  1. `Protection controls`
     `encryption, masking, tokenization`
  2. `Access & policy controls`
     `least privilege, isolation, egress`
  3. `Platform & workload controls`
     `secure processing, credentials, backups`
  4. `Network & environment controls`
     `boundaries, segmentation, secure transport`
- Make the layers visibly support and protect the Data panel above them. Use subtle upward directional cues, nesting, or shielding contours without depicting a literal castle wall or perimeter.
- Add one vertical or side-spanning band labeled exactly:
  - `Monitoring & detection`
  - `audit trails, anomalies, extraction signals`
- The Monitoring & detection band must visibly connect to or span all four defensive layers, not appear as a separate final step.
- Add the exact footer caption:
  - `Protect data across systems and boundaries—not merely one perimeter.`

Visual hierarchy:

- Make `Data` the clearest focal point.
- Make the four defensive layers distinct but visually related, progressing from data-near controls to environmental controls.
- Use the spanning monitoring band as a strong cross-cutting visual element.
- Keep secondary examples smaller than each layer title but readable at documentation-page width.

Style:

- crisp vector-style editorial infographic
- light neutral background with generous whitespace
- restrained navy, teal, muted blue, and soft gray palette
- a single warm accent color may be used sparingly for Monitoring & detection
- large, highly legible sans-serif typography
- flat two-dimensional shapes with subtle borders
- balanced, calm, vendor-neutral, and concept-first
- consistent with a modern technical documentation site

Constraints:

- Render every specified label exactly as written.
- Show exactly four defensive layers beneath the Data panel.
- Monitoring & detection must visibly span all four defensive layers.
- Do not imply that network controls alone contain or protect all data.
- Do not depict the layers as a sequential workflow; they operate together.
- Do not use a generic padlock, shield hero icon, hacker silhouette, hooded person, binary-code background, server-rack photograph, globe, cloud-provider logo, or stock cybersecurity imagery.
- Do not add product names, vendor logos, compliance badges, decorative prose, 3D effects, gradients, excessive shadows, or watermarks.
- Avoid tiny text, dense control catalogs, and architectural implementation detail.
