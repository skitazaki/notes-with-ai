# 画像生成プロンプト — ハーネスエンジニアリング

## コンセプト

**ハーネスエンジニアリング** というタイトルの、明快で整理されたカバー画像を作成してください。入力された開発文脈と人のレビューの間にある、制御されたシステムとしてハーネスを一目で示します。中央のハーネスはモデルに渡す情報を整え、モデルのツール利用を制御し、実行環境を制約します。証拠は人に渡され、人のレビューは次の反復に活用されます。

## レイアウト

**16:9** の横長構図にしてください。目安は **1536 × 864 ピクセル**です。左から右へ読む、幅の異なる大きな3列を配置します。

1. **入力** — **タスク**、**参照資料**、**スキルライブラリ** を、区切りのある3行にした小さなカードです。
2. **ハーネス** — 中央に置く最も幅広く目立つ列です。一つの明確な境界で囲みます。内部には、**準備された指示 / コンテキスト / スキル** → **モデル** → **制御されたツールアクセス** → **制約された実行環境** の流れを置きます。準備された情報は3行で示す一つのグループにし、3つの別々のボックスにはしません。ツールアクセスと実行環境は別のボックスにします。
3. **人のレビュー** — **証拠** と、それを確認する人を含む小さな右列です。

列を接続し、次のフィードバック循環を示します。

- 入力 → ハーネス: 入力カードからの矢印はハーネスの境界で止めます。準備された情報のボックスを矢印の接続先にしないでください。
- ハーネス内部: 準備された指示 / コンテキスト / スキル → モデル → 制御されたツールアクセス → 制約された実行環境。
- ハーネス → 証拠 → 人のレビュー: 出力の矢印は内部の構成要素からではなく、ハーネスの境界から出します。
- 人のレビュー → ハーネス: 3列の下を通る曲線の戻り矢印を1本だけ描き、レビューが次の反復に反映されることを示します。この戻り経路には **フィードバック** とラベルを付けます。

入力、証拠の出力、レビューの戻りに使う境界の接続点は、それぞれ間隔を空けて配置してください。矢印がタイトル、ボックス、ほかの矢印と重ならないようにします。フィードバックの弧は追いやすくしつつ、主図を囲んだり横切ったりしないでください。

## 視覚要素

- 画像内の正確なタイトルは **ハーネスエンジニアリング** です。サブタイトルは使わないでください。
- 次のラベルだけを使用してください。**入力**、**タスク**、**参照資料**、**スキルライブラリ**、**ハーネス**、**準備された指示**、**コンテキスト**、**スキル**、**モデル**、**制御されたツールアクセス**、**制約された実行環境**、**証拠**、**人のレビュー**、**フィードバック**。
- 入力カードでは、タスク、参照資料、スキルライブラリを細い水平線で区切った別々の行にします。準備された情報のまとまりでも、準備された指示、コンテキスト、スキルを同じ区切り方で別々の行にします。各グループには共通の外枠を一つだけ使い、各行を個別の枠で囲まないでください。
- スキルはモデルを導く再利用可能な指示とリソースとして示します。実行可能なツールや権限付与として描かないでください。
- 中央のハーネスを識別できる外枠を設けます。入力が入り、証拠が出て、人のフィードバックが戻る三つの接続点を読み取れるようにしてください。
- **制御されたツールアクセス** と **制約された実行環境** を別々に示します。前者はモデルが要求できる操作を制限し、後者は操作が実際に影響する場所を制限します。
- 人のレビューを出力の到達点とし、そこからフィードバックの戻り経路が始まることを示してください。

## スタイル

技術ドキュメントサイト向けの、落ち着いた、情報を整理して伝えるインフォグラフィックにしてください。温かみのある明るい背景、濃紺の文字と線、控えめなティールとアンバーを使います。中央列を最も目立たせ、左右の列は簡潔にし、ハーネスの境界を明瞭にします。記事本文のカラム幅でもラベルが読める大きさにしてください。アイコンは補助的に使い、構成と矢印で意味を伝えます。

## 禁止事項

- 指定したラベル以外のボックスやラベルを追加しないでください。
- 一方向の工程図にしないでください。3列は入力、制御されたシステム、レビューを示し、戻り経路は一つだけにします。
- 入力矢印を準備された指示、コンテキスト、スキルへ直接つながないでください。接続先はハーネスの境界です。
- 内部の構成要素から人のレビューへ証拠を直接つながないでください。出力はハーネスの境界から出します。
- 人のレビュー → フィードバック → ハーネスの戻り循環を省略したり、別の経路に変えたりしないでください。
- 制御されたツールアクセスと制約された実行環境を一つにまとめないでください。
- ファイルシステム、ネットワーク、認証情報、本番環境への無制限なアクセスを描かないでください。
- 事業者名や製品名、ロゴ、メトリクス、架空のコード、透かし、装飾的な回路模様、指定外のワークフロー段階を加えないでください。
- **16:9** の比率を守り、十分な余白を保ってください。
