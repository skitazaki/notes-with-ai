# Image Generation Prompt - Architecture Zoom Map

Create a publication-quality conceptual diagram titled "Architecture Zoom Map". The image must be fully self-contained and understandable without reading the article or any surrounding text.

Create a clean editorial infographic with a light background, 16:9 wide layout, and a restrained 5-6 color palette. Use crisp vector-style shapes and readable labels. Keep the design vendor-neutral: no logos, product branding, or cloud/deployment diagrams.

The figure should explain that architecture reasoning starts with classification by lens, then uses supporting guidance to inform design decisions. The main organizing center is "Architecture Dimensions". From that hub, draw five balanced branches: Structural, Operational, Strategic, Ownership, and Communication. Match the article language closely: Structural: Layers; Operational: Planes, Flows and Pipelines; Strategic: Pillars; Ownership: Ownership Boundaries; Communication: Views and Viewpoints.

Use distinct but coordinated visual treatments for each branch so the differences are obvious, while keeping all five branches visually balanced. Structural should read as layered abstraction or decomposition. Operational should read as runtime behavior and movement across a system. Strategic should suggest qualities, constraints, and priorities. Ownership should show responsibility boundaries and grouped domains. Communication should suggest stakeholder-facing views and framed perspectives.

From the central "Architecture" node, create a secondary supporting branch to three smaller nodes: Architecture Principles, Architecture Constraints, and Decision Frameworks. These should be visually subordinate to Architecture Dimensions. The key message is that dimensions organize the way teams reason about the system, while principles, constraints, and decision frameworks provide the guidance that shapes the final design.

Add a subtle left-to-right or top-to-bottom flow: Architecture -> Dimensions -> Reasoning lens -> Supporting guidance -> Design decision.

Suggested alt text: "Architecture Zoom Map showing architecture organized by dimensions, including structural, operational, strategic, ownership, and communication lenses, with supporting guidance from principles, constraints, and decision frameworks."

Do:
- keep the diagram clean, readable, and editorial
- emphasize the distinction between reasoning lenses and guidance layers
- make the structure easy to scan in one glance
- reinforce that architecture is not one master diagram but a set of complementary lenses
- keep labels concise and publication-ready

Do not:
- turn the image into a deployment diagram or cloud topology
- make it look like an org chart or product architecture map
- clutter the canvas with tiny text or excessive detail
- imply that the five dimensions are interchangeable
- make the supporting guidance nodes appear as the main organizing framework
- include vendor branding or logos

Audience: experienced software engineers, architects, technical leaders, platform engineers, engineering managers
