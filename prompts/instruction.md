When the coding agent creates or revises an image prompt, keep the content structurally consistent.

Every image prompt should use the same four labeled elements in this order:

1. **Concept**
   Explain the core message the image should communicate.
   State the idea, comparison, process, relationship, or organizational model the image is meant to clarify.

2. **Layout**
   Describe how the image should be organized spatially.
   Specify where the main elements should appear, how they should be grouped, and what visual hierarchy should guide the reader.

3. **Visual cues**
   Identify the specific shapes, icons, arrows, labels, contrasts, or symbolic elements that should carry meaning.
   Make clear which visual elements correspond to which concepts in the source content.

4. **Style**
   Describe the overall visual character of the image.
   Specify whether it should feel minimal, editorial, technical, diagrammatic, modern, neutral, or presentation-oriented.

Consistency rules:

- Keep the prompt aligned with the source page's central concept.
- Prefer one clear message per image rather than combining multiple competing ideas.
- Use terminology that matches the source document consistently.
- Make the layout easy to scan and suitable for documentation or knowledge-site use.
- Avoid vague style language such as "nice," "cool," or "modern" without concrete direction.
- Avoid decorative elements that do not reinforce the meaning.
- If the image compares patterns or models, make the basis of comparison visually obvious.
- If the image explains a flow or evolution, make sequence and direction explicit.

Recommended output pattern:

- **Concept:** ...
- **Layout:** ...
- **Visual cues:** ...
- **Style:** ...

The goal is to help the agent produce image prompts that are predictable in structure, consistent in terminology, and tightly connected to the meaning of the content page.
